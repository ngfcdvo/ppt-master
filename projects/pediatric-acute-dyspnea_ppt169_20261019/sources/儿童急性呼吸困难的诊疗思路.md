# 儿童急性呼吸困难的诊疗思路

## 摘要

呼吸困难是儿科急诊常见的就诊主诉。儿童呼吸困难病情急、发展快，若不能及时识别并正确处理，极易进展为呼吸衰竭甚至心跳骤停。文章从呼吸困难的定义与分类、病理生理机制、不同病因所致呼吸困难的临床表现、呼吸困难的评估与诊断步骤以及治疗原则等 6 个方面，全面地阐述了儿童呼吸困难的诊疗思路。

__关键词__：儿童；呼吸困难；诊疗思路

## 引言：为什么要建立规范的诊疗思路

- 呼吸困难（dyspnea）是儿童急诊最常见的就诊原因之一
- 儿童尤其是婴幼儿：呼吸道管径细小、气道阻力高
- 呼吸功能储备低，而氧代谢需求高
- 各种肺内外疾病易导致儿童呼吸困难，甚至发展为呼吸衰竭、心跳骤停等严重后果
- 因此，建立系统、规范的呼吸困难诊疗思路，对提高呼吸困难患儿的救治成功率、改善患儿预后至关重要

## 1 呼吸困难的定义及分类

### 1.1 定义

- 呼吸困难指患者自觉空气不足、呼吸费力或窒息等呼吸不适的__主观体验__
- 伴或不伴呼吸费力的__客观表现__：张口呼吸、点头呼吸、呻吟、鼻翼扇动、三凹征等
- 并可有呼吸频率、深度与节律的改变
- 呼吸困难既是__症状__，也是__体征__
- 注意：婴幼儿因年龄、语言及社会心理等因素的影响，不能准确描述呼吸困难，__主要根据客观体征来判断__

### 1.2 分类

- __按病程__：急性呼吸困难（病程 3 周以内）与慢性呼吸困难（持续 3 周以上）
- __按病因__：肺源性、心源性、中毒性、血源性、神经精神性呼吸困难
- __按发生时相__：吸气性、呼气性及混合性呼吸困难
- 小儿呼吸困难多为急性，病程进展快，可迅速危及生命，需要紧急明确病因和处理

## 2 呼吸困难的机制

### 2.1 正常呼吸动作：经典神经反射弧

中枢/外周化学感受器或机械感受器感知机体内环境和肺部机械张力的变化 → 信号经迷走神经、舌咽神经传入脑干呼吸中枢 → 经膈神经和肋间神经将指令传至膈肌和肋间外肌 → 产生呼吸动力 → 驱动空气经气道进入肺泡 → 完成通气过程

### 2.2 导致呼吸困难的四类因素

一切导致感受器内环境变化、气道不畅、中枢及神经肌肉异常的因素均会导致呼吸困难：

1. __缺氧及高碳酸血症__
	- 各种肺内、肺外疾病引起缺氧或高碳酸血症时，刺激颈动脉体、主动脉弓或中枢化学感受器，反射性兴奋呼吸中枢，使呼吸加深加快
	- 二氧化碳（CO₂）升高能迅速通过血脑屏障，在脑脊液中生成氢离子（H⁺），刺激中枢感受器，是呼吸调节__最重要的化学因素__
	- 另外，肺淤血、炎症、间质水肿和间质性肺疾病等也会刺激肺牵张感受器，诱发呼吸急促和呼吸困难
2. __呼吸运动阻力增加__
	- 上呼吸道梗阻、下气道平滑肌痉挛、胸膜疾病（如气胸、大量胸腔积液）等导致气道阻力增加
	- 胸壁呼吸肌内的本体感受器激活，传导到脑干及皮质感觉中枢的信号增多，反射性引起呼吸肌做功增强，出现呼吸困难的主观和客观表现
3. __呼吸肌受损__
	- 呼吸肌力减退、麻痹：如肌炎、吉兰\-巴雷综合征、重症肌无力
	- 中枢对呼吸肌肉的传出冲动增加，变为通气异常感受信号，经肺部迷走神经受体及呼吸肌的机械感受器传入大脑感觉运动皮层，产生呼吸困难感受
4. __呼吸驱动异常__
	- 中枢神经系统疾病（脑炎、颅内高压）、麻醉镇静剂等，可直接损害或抑制呼吸中枢，导致呼吸节律异常

## 3 急性呼吸困难的病因及表现

### 3.1 肺源性呼吸困难

可表现为吸气性、呼气性和混合性呼吸困难：

| 类型 | 病变部位/疾病 | 临床表现 |
| --- | --- | --- |
| 吸气性呼吸困难 | 喉、气管、大支气管病变：急性喉炎、喉软化、气道异物、外部病变压迫等引起的中心气道狭窄与阻塞 | 吸气费力，三凹征，张口呼吸，可伴剧烈干咳及高调吸气性喉鸣 |
| 呼气性呼吸困难 | 哮喘急性发作、毛细支气管炎、喘息性支气管炎等 | 呼气延长及费力，常伴有呼气相哮鸣音 |
| 混合性呼吸困难 | 重症肺炎、肺水肿、气胸、大量胸腔积液、弥漫性肺间质疾病等 | 吸气及呼气时均感费力，呼吸增快，肺部闻及干湿啰音，呼吸音增强或减弱 |

### 3.2 心源性呼吸困难

- __机制__：各种原因引起的左心功能不全致肺淤血和肺泡弹性减低，气体弥散功能下降，肺泡张力增高，刺激肺牵张感受器，兴奋迷走神经，以及肺循环压力升高对呼吸中枢的反射性刺激所致
- __特点__：呼吸急促、费力，两肺湿啰音及哮鸣音，与肺炎、急性呼吸窘迫综合征所致的混合性呼吸困难难以鉴别
- __鉴别要点（与肺部疾病的区别）__：
	- 精神面色差，与肺部疾病的严重程度不相符
	- 常有烦躁不安、拒奶、汗多等非特异性表现
	- 查体有心音低、奔马律、肝大等体征
	- 胸片示心影增大
	- 床旁超声左室射血分数降低、下腔静脉塌陷 < 50%
	- 血脑钠肽增高
	- 经强力抗感染、雾化止喘等治疗效果不佳
- 出现上述情况时应考虑心源性呼吸困难可能

### 3.3 中毒性呼吸困难

- __机制__：各种代谢性疾病引起的代谢性酸中毒、糖尿病酮症酸中毒、休克等，均可使血氢离子浓度升高、pH 值降低，刺激外周化学感受器或直接兴奋呼吸中枢所致
- __典型表现__：深大、急促、规则的呼吸（Kussmaul 呼吸），肺部常无阳性体征
- __中枢抑制药物中毒__：呼吸缓慢、变浅，伴节律异常
- __有机磷中毒__：呼吸道大量泡沫样分泌物，兼有呼吸肌无力和中枢驱动衰竭的特点

### 3.4 血源性呼吸困难

- __本质__：血红蛋白的量和质异常，如严重贫血、一氧化碳中毒、氰化物中毒、摄入亚硝酸盐过量等
- __机制__：血液携氧能力下降或氧的运输过程受阻 → 组织细胞缺氧 → 兴奋呼吸中枢
- __特点__：
	- 呼吸浅而快、心率增快，呼吸心率比例正常
	- 常无呼吸费力及肺部阳性体征，肺部影像无异常
	- 伴有面色苍白或紫绀等血液病体征

### 3.5 神经精神性呼吸困难

- __中枢性（器质性）__：
	- 脑炎、脑出血、肿瘤等所致颅内压增高，使脑干移位、缺血或受压，破坏呼吸节律的产生与传导通路
	- 导致呼吸节律紊乱：如潮式呼吸、抽泣样呼吸或间停呼吸
- __精神性（癔症、焦虑等）__：
	- 呼吸快而浅，但无呼吸困难的客观表现，体检肺部无阳性体征
	- 患儿主诉多、症状重，常因过度通气发生呼吸性碱中毒，出现胸闷、口舌及肢体麻木、手足搐搦等

## 4 急性呼吸困难的分度与评估

### 4.1 呼吸困难的分度（轻、中、重度）

| 分度 | 临床表现 |
| --- | --- |
| 轻度 | 仅有呼吸频率加快，活动、哭闹或吃奶后出现轻度发绀 |
| 中度 | 呼吸明显加快，有呼吸做功增加及辅助呼吸肌参与表现（如三凹征、鼻翼扇动、点头样呼吸），烦躁发绀，吸氧后症状可改善 |
| 重度 | 呼吸困难进一步加重，出现明显紫绀、呼吸节律不规则或呼吸暂停等表现，可伴有昏迷及循环功能不全 |

### 4.2 呼吸困难的评估：ABCDE 步骤

主要根据病史、临床表现与体征、发展速度，快速识别是否存在危及生命的情况，以指导紧急处理的优先级。按 ABCDE 步骤评估：

- __A（Airway，气道）__：评估气道是否通畅，有无异物、喉鸣、喘鸣
- __B（Breathing，呼吸）__：评估呼吸频率、呼吸做功、有无异常呼吸音及异常体位
- __C（Circulation，循环）__：评估心率、血压、肤色、有无发绀或花纹等循环状态
- __D（Disability，神经功能）__：评估意识及反应状态，有无烦躁、嗜睡或昏迷
- __E（Exposure，暴露）__：询问病史，全面查体，观察面色，有无皮疹、水肿、外伤等

初步评估后，应辨别患儿是否为上气道或下气道梗阻、肺实质/胸膜疾病、心源性呼吸困难，或其他原因。这一"定位"思路有助于快速明确病因，给予相应的紧急处理。

## 5 急性呼吸困难的病因诊断思路（4 个步骤）

建议对急性呼吸困难患儿按以下 4 个步骤进行病因分析：

### 5.1 第一步：区分吸气性或呼气性呼吸困难

- 吸气性呼吸困难：病变在__胸外大气道__（喉、声门下、气管）
- 呼气性呼吸困难：病变在__胸内小气道__，如支气管哮喘、毛细支气管炎等

### 5.2 第二步：区分喘息性疾病与呼吸急促

- 喘息与呼吸急促有时难以准确区分
- __有典型哮鸣音__ → 提示存在支气管痉挛或狭窄 → 患儿多为毛细支气管炎、喘息性支气管炎、支气管哮喘等
- __无哮鸣音、仅为呼吸急促__ → 可能为肺间质性或血管性疾病，并警惕肺外及全身性疾病（如中毒性、血源性或精神性呼吸困难）
- 根据病史与临床表现，以及血气等辅助检查结果可明确

### 5.3 第三步：识别混合性呼吸困难

- 当患儿既无典型的吸气性三凹征，也无典型的哮鸣音，而是呈现__全程呼吸急促、费力__时，为混合性呼吸困难
- 常见于重症肺炎肺实变、大量胸腔积液、心功能不全、急性呼吸窘迫综合征等肺源性疾病，以及各种原因引起的心功能不全
- 二者的鉴别要点如前所述（见 3.2 心源性呼吸困难）

### 5.4 第四步：注意缓慢型呼吸困难

- 这类呼吸困难__容易被忽略，需特别警惕__
- 若患儿表现为__呼吸浅慢、呼吸节律不规整、伴呼吸幅度降低，而非呼吸频率增快__，提示神经系统或呼吸肌受累性疾病
- 常见病因：颅内感染、出血所致颅高压，使用镇痛镇静药物，吉兰\-巴雷综合征、重症肌无力等
- 结合病史、神经系统体征、头颅影像学检查可进一步鉴别

- 见于神经系统疾病（颅内感染/出血致颅高压、吉兰\-巴雷综合征）、重症肌无力、镇静药物、中毒等

## 6 急性呼吸困难的治疗原则

- 对所有呼吸困难患儿应遵循\*\*"先救命、后治病"\*\*的原则，进行严重度评估

__对中重度呼吸困难的处理：__

1. __开放气道__：保持呼吸道通畅
2. __监护__：进行心电和氧饱和度监护
3. __建立静脉通路__
4. __呼吸支持（立即给予）__：根据严重程度选择适当的氧疗方式——鼻导管、面罩、经鼻高流量氧疗或无创通气，纠正低氧血症
5. __有创机械通气启动指征__：
	- 意识改变
	- 严重低氧血症
	- 二氧化碳进行性升高
	- 呼吸肌疲劳
	- 应及时启动有创机械通气，避免持续的低氧血症或高碳酸血症，导致昏迷甚至呼吸心跳骤停

__稳定生命体征的同时，快速明确病因，根据病因进行治疗：__

| 病因 | 治疗 |
| --- | --- |
| 喉头水肿 | 给予肾上腺素和糖皮质激素 |
| 气道异物 | 立即行支气管镜取出 |
| 大量胸腔积液 | 行胸腔穿刺减压 |
| 重症肺炎 | 尽快经验性抗感染治疗 |
| 心源性呼吸困难 | 强调利尿、扩血管、强心等治疗 |

## 7 呼吸障碍

- 根据呼吸困难的定义，呼吸困难既包括__呼吸急促（窘迫）__，又包括__呼吸浅慢、呼吸肌麻痹所致空气不够用的窒息感__
- 成人和较大儿童能主动描述这种不适感，而婴幼儿不能准确表达，需要医生依赖客观体征判断
- 但临床上的普遍认知是"呼吸困难 = 呼吸急促/窘迫"，对表现为"慢、浅、弱"的呼吸困难容易忽视
- 为此，本文参照心律失常的分类（快速型和缓慢型），提出\*\*"呼吸障碍"\*\*这一名词，包括快速型和缓慢型 2 个类型：

__快速型呼吸障碍__：即表现为呼吸急促或费力的呼吸困难

__缓慢型呼吸障碍__：

- 以呼吸频率减慢、通气不足为特征
- 患儿常表现为安静、少动、咳声低微、吸吮无力等
- 病因主要是神经肌肉疾病、电解质紊乱以及药物因素（如麻醉手术中阿片类或镇静药物的应用）
- 随着临床上操作和新技术应用的增多，缓慢型呼吸障碍可能会更加常见

__意义__：提出这个概念是提醒广大儿科医生加强对缓慢型呼吸障碍的认识和重视，避免遗漏而导致原本不难挽回的严重后果。
